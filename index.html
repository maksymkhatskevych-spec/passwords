Импорт из браузера

1. Сохраните пароли из браузера в CSV‑файл:

Chrome, Яндекс, Opera

Откройте адрес chrome://password-manager/settings (в Яндексе — browser://passwords, в Opera — opera://password-manager/settings) → «Экспорт паролей» → «Скачать файл».

Edge

Откройте edge://wallet/passwords → «⋯» (Настройки) → «Экспорт паролей».

Firefox

Откройте about:logins → «⋯» справа вверху → «Экспортировать пароли».

Safari (Mac)

Меню «Файл» → «Экспортировать» → «Пароли» или приложение «Пароли» → «Файл» → «Экспортировать все пароли».

Bitwarden, 1Password, KeePass

Экспорт в формате CSV (не JSON и не зашифрованный).

Синхронизация через GitHub

Зашифрованная копия хранилища лежит в вашем приватном репозитории. GitHub видит только шифр — без мастер‑пароля его не прочитать. Нужно сделать один раз:

1. Создайте приватный репозиторий

github.com → «+» справа вверху → New repository → имя, например passwords-data → обязательно Private → Create repository. Это отдельный репозиторий, не тот, где лежит сайт.

2. Создайте токен доступа только к нему
  1. Откройте github.com/settings/personal-access-tokens/new
  2. Token name: «Пароли»; Expiration — например, 1 год
  3. Repository access → Only select repositories → выберите passwords-data
  4. Permissions → Repository permissions → Contents → Read and write
  5. Generate token → скопируйте его (начинается с github_pat_)

Токен хранится внутри зашифрованного хранилища. На втором устройстве нажмите на экране входа «У меня уже есть хранилище на другом устройстве».
